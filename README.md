## 🚀 ୨. କମ୍ପ୍ୟୁଟର ଓ ୱିଣ୍ଡୋଜ୍‌ରେ ଚଳାଇବା ପାଇଁ (Windows Quick Start)

2. ଏହା ସ୍ୱୟଂଚାଳିତ ଭାବେ କ୍ଲାସରୁମ୍ ସର୍ଭର ଚାଲୁ କରିବ ଏବଂ ଆପଣଙ୍କ ଡିଫଲ୍ଟ ବ୍ରାଉଜରରେ ଆପ୍ଲିକେସନ୍ ଖୋଲିବ।

### ବିକଳ୍ପ ୨: କମାଣ୍ଡ ପ୍ରମ୍ପ୍ଟ କିମ୍ବା ଟର୍ମିନାଲ୍ ଦ୍ୱାରା

cd "c:\Users\HP\Documents\ITIHAS GYAN"

# ୨. ସର୍ଭର ଚାଲୁ କରନ୍ତୁ

## 📱 ୩. ଆଣ୍ଡ୍ରଏଡ୍ APK ସ୍ଥାପନ (Android APK Installation)

ପ୍ରୋଜେକ୍ଟରେ ସମ୍ପୂର୍ଣ୍ଣ ପ୍ରସ୍ତୁତ, କମ୍ପାଇଲ୍ ହୋଇଥିବା ପ୍ରକୃତ Android APK ଅନ୍ତର୍ଭୁକ୍ତ:
- **APK File Location:** `dist/itihas-gyan-release.apk`
- **Native Build Path:** `android/app/build/outputs/apk/debug/app-debug.apk`
- **Package ID:** `com.itihasgyan.app`
- **Application Name:** `ITIHASH GYAN` (UI displaying `ଇତିହାସ ଜ୍ଞାନ`)

### ଫୋନ୍ ବା ଡିଜିଟାଲ୍ ଫ୍ଲାଟ ପ୍ୟାନେଲ୍‌ରେ ଇନଷ୍ଟଲ୍ କରିବା ପ୍ରଣାଳୀ:
1. `dist/itihas-gyan-release.apk` ଫାଇଲ୍‌ଟିକୁ Android ଫୋନ୍, ଟାବଲେଟ୍ କିମ୍ବା ଇଣ୍ଟରାକ୍ଟିଭ୍ ଫ୍ଲାଟ୍ ପ୍ୟାନେଲ୍ (IFP) କୁ କପି କରନ୍ତୁ କିମ୍ବା ୱେବ୍ ଆପ୍ଲିକେସନ୍‌ର Settings ସେକ୍ସନରୁ "Download Android APK" ବଟନ୍ ଦବାଇ ଡାଉନଲୋଡ୍ କରନ୍ତୁ।
2. ଫାଇଲ୍ ମ୍ୟାନେଜରରୁ APK ଫାଇଲ୍ ଉପରେ ଟ୍ୟାପ୍ କରନ୍ତୁ।
3. ଯଦି "Install unknown apps" ଚେତାବନୀ ଆସେ, "Allow from this source" କୁ ଅନ୍ କରନ୍ତୁ।
4. "Install" ଦବାନ୍ତୁ ଏବଂ ଆପ୍ ଖୋଲନ୍ତୁ।
5. ଏହା ସମ୍ପୂର୍ଣ୍ଣ ଅଫଲାଇନ୍ ଏବଂ ଲୋକାଲ୍ ଡାଟାବେସ୍ ସହ କାମ କରେ।

## 🖥️ ୪. ତିନୋଟି ମୁଖ୍ୟ ଇଣ୍ଟରଫେସ୍ (Three Connected Interfaces)

### A. ଅଧ୍ୟାପକ ନିୟନ୍ତ୍ରଣ ସ୍କ୍ରିନ୍ (Teacher Control Interface)
- ଛାତ୍ର ତାଲିକା ଏକ୍ସେଲରୁ ଆମଦାନୀ।
- AI ଦ୍ୱାରା ପ୍ରଶ୍ନ ପ୍ରସ୍ତୁତି ଓ ଅନୁମୋଦନ।
- ସ୍ଥାୟୀ ପ୍ରଶ୍ନ ବ୍ୟାଙ୍କ ପରିଚାଳନା।
- ଲାଇଭ୍ କୁଇଜ୍ ସେସନ୍ ଆରମ୍ଭ (ଅନନ୍ୟ QR Code, Join Link ଓ Session PIN)।
- ପ୍ରଶ୍ନ ପରିବର୍ତ୍ତନ, ଟାଇମର୍ (15s, 30s, 45s, 60s, custom, off)।
- ହାତ ଟେକିବା କ୍ରମ (Rank 1, 2, 3...) ଦେଖି ଛାତ୍ର ଚୟନ।
- ମାର୍କ ପ୍ରଦାନ (Correct, Incorrect, Partial, Bonus, No Marks)।
- ଉତ୍ତର ପ୍ରକାଶ (Reveal Answer - ସଠିକ୍ ଉତ୍ତର ସବୁଜ ଓ ଭୁଲ୍ ଲାଲ୍)।
- ବିସ୍ତୃତ ବ୍ୟାଖ୍ୟା (Show Description - ପ୍ରତ୍ୟେକ ବିକଳ୍ପର ଐତିହାସିକ ଯାଞ୍ଚ)।
- ଲାଇଭ୍ ଲିଡରବୋର୍ଡ୍ ଏବଂ ଫଳାଫଳ ରପ୍ତାନି।

### B. ଡିଜିଟାଲ୍ ଫ୍ଲାଟ୍ ପ୍ୟାନେଲ୍ ଓ ପ୍ରୋଜେକ୍ଟର ସ୍କ୍ରିନ୍ (Classroom Presentation Interface)
- ୬୫"/୭୫"/୮୬" ଇଣ୍ଟରାକ୍ଟିଭ୍ ଫ୍ଲାଟ୍ ପ୍ୟାନେଲ୍ ଓ ପ୍ରୋଜେକ୍ଟର ପାଇଁ ସ୍ୱତନ୍ତ୍ର ଫୁଲ୍ ସ୍କ୍ରିନ୍ ଲେଆଉଟ୍।
- ଅତ୍ୟନ୍ତ ବଡ଼, ସ୍ପଷ୍ଟ ଓଡ଼ିଆ ଓ ଇଂରାଜୀ ଫଣ୍ଟ୍ (Noto Sans Oriya)।
- ଉପସ୍ଥିତ ଛାତ୍ର ସଂଖ୍ୟା, ହାତ ଟେକା ସଂଖ୍ୟା ଓ ଟପ୍ ୩ ଛାତ୍ରଙ୍କ ପୋଡିୟମ୍।
- ଶିକ୍ଷକ ଉତ୍ତର ଖୋଲିବା ମାତ୍ରେ ସ୍ୱୟଂଚାଳିତ ଭାବେ ସଠିକ୍ ଉତ୍ତର ହାଇଲାଇଟ୍।

### C. ଛାତ୍ରଛାତ୍ରୀ ମୋବାଇଲ୍ ସ୍କ୍ରିନ୍ (Student Mobile Participation Interface)
- ଛାତ୍ରଛାତ୍ରୀଙ୍କୁ କୌଣସି ଆପ୍ ଇନଷ୍ଟଲ୍ କରିବାକୁ ପଡ଼ିବ ନାହିଁ।
- କ୍ଲାସରୁମର QR କୋଡ୍ ସ୍କାନ୍ କରି କିମ୍ବା Join Link / PIN ଦ୍ୱାରା ମୋବାଇଲ୍ ବ୍ରାଉଜରରେ ଖୋଲିବେ।
- କଲେଜ ରୋଲ୍ ନମ୍ବର ଦେବା ମାତ୍ରେ ତାଙ୍କ ନାମ ସ୍ୱୟଂଚାଳିତ ଭାବେ ପ୍ରଦର୍ଶିତ ହେବ।
- ବଡ଼ "Raise Hand" (ହାତ ଟେକନ୍ତୁ) ବଟନ୍।
- ନାନୋସେକେଣ୍ଡ ସର୍ଭର ଟାଇମଷ୍ଟାମ୍ପ ଅନୁସାରେ ତାଙ୍କୁ ତୁରନ୍ତ ରାଙ୍କ୍ (#1, #2, #3...) ସ୍ୱୀକୃତି ମିଳିବ।
- ବାରମ୍ବାର ଟ୍ୟାପ୍ ବା ସ୍ପାମ୍ ନିରୋଧକ ସୁରକ୍ଷା।

## 🎓 ୬. ପ୍ରଶିକ୍ଷଣ ଓ ବ୍ୟବହାର ନିର୍ଦ୍ଦେଶାବଳୀ (Teacher Workflow Guide)

1. **ଛାତ୍ର ନାମଲେଖା:**  
   ମୁଖ୍ୟ ପୃଷ୍ଠାରୁ "Student Database" କୁ ଯାଇ ନିଜ କ୍ଲାସର Excel କିମ୍ବା CSV ଫାଇଲ୍ Import କରନ୍ତୁ କିମ୍ବା ସିଧାସଳଖ ଟେମ୍ପଲେଟ୍ ଡାଉନଲୋଡ୍ କରି ଭରନ୍ତୁ।
2. **ପ୍ରଶ୍ନ ପ୍ରସ୍ତୁତି:**  
   "Create Questions with AI" ରେ ଇତିହାସ ବହିର ପାରାଗ୍ରାଫ୍ ପେଷ୍ଟ କରନ୍ତୁ। Gemini API key ଦେଇ କିମ୍ବା ଅଫଲାଇନ୍ ଜେନେରେଟର ଦ୍ୱାରା MCQ, ୨ ମାର୍କ, ୫ ମାର୍କ ପ୍ରଶ୍ନ ପ୍ରସ୍ତୁତ କରନ୍ତୁ ଏବଂ ଅନୁମୋଦନ କରି ସ୍ଥାୟୀ ପ୍ରଶ୍ନ ବ୍ୟାଙ୍କରେ ସେଭ୍ କରନ୍ତୁ।
3. **ଲାଇଭ୍ କ୍ଲାସ୍ କୁଇଜ୍:**  
   "Start Live Quiz" ବଟନ୍ ଦବାନ୍ତୁ। ସ୍କ୍ରିନ୍‌ରେ ଦେଖାଯାଉଥିବା QR Code କୁ ପ୍ରୋଜେକ୍ଟର ବା ଫ୍ଲାଟ ପ୍ୟାନେଲ୍‌ରେ ଦେଖାନ୍ତୁ।
4. **ଛାତ୍ର ଯୋଗଦାନ:**
